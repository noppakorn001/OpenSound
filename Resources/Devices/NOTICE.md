# Device product renders

These 14 product renders are retained without visual edits from SonyBridge's
`Client/resources/devices` directory at commit
`8c81a2775a76097f4938fbc835411bd59088014c`.
Upstream identifies them as official Sony product renders.
The upstream MIT license is retained in `LICENSE.SonyBridge`.

owners; the code license is not a claim of ownership of that material.

The interface selects an image by a matching reported model or device name.
Image availability does not imply that a model's controls are hardware tested.
The cow application icon is a separate, user-supplied asset.
