# Support

Search [existing issues](https://github.com/noppakorn001/OpenSound/issues) before opening a report. Use the bug form for reproducible problems and the device form for model compatibility. Include the OpenSound version, macOS version, model, firmware and sanitized steps. Use an ordinary issue for feature proposals or development questions.

Never attach passwords, tokens, Bluetooth addresses, personal device names, pairing history, the proprietary IPA or raw diagnostic captures. Report vulnerabilities through [private vulnerability reporting](https://github.com/noppakorn001/OpenSound/security/advisories/new), following [SECURITY.md](SECURITY.md).

OpenSound is a volunteer community project with no guaranteed response time or support contract. Only the models and functions documented in [device support](docs/DEVICE_SUPPORT.md) have the stated evidence; a matching product image does not establish compatibility. Sony's account/cloud services and firmware updating are outside the current scope.

For development and forks, start with [CONTRIBUTING.md](CONTRIBUTING.md) and [development setup](docs/DEVELOPMENT.md). Do not send private device recordings directly to contributors unless they have agreed on a secure, minimal disclosure process.
