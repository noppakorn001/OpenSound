## Build and export without Sony imagery

```sh
OPENSOUND_DEVICE_IMAGES=none bash scripts/build.sh
OPENSOUND_DEVICE_IMAGES=none bash scripts/package-source.sh
```

The first command omits device renders from the app and clears stale bundled renders. The UI falls back to its generic system illustration. The second omits device PNGs and demonstration screenshots from the source archive; documentation image links in that reduced archive intentionally have no bundled screenshots. MIT source, the MIT cow logo and third-party license notices are retained. These commands do not remove images from the checkout or change an already installed application.

New artwork contributions must identify their creator, source and explicit redistribution license. Do not copy images from an IPA, marketing website or another repository merely because they can be downloaded.
